📚 Fuentes oficiales y canales de información

Transparencia de fuentes: los datos meteorológicos se contrastan entre modelos Open-Meteo (ECMWF, GFS, ICON y GEM), MET Noruega, radar RainViewer, satélite GOES/NASA y observaciones METAR de aeropuertos. Los avisos oficiales se identifican por separado. Los detalles de cada alerta muestran la evidencia disponible para esa detección; una fuente sin respuesta se informa como no disponible, nunca como ausencia de riesgo.

Versión web: GitHub Pages no incluye el proxy nativo de la APK: SMN, INPRES, METAR y Contingencias se leen mediante un proxy web (propio si está configurado, o públicos de respaldo que pueden fallar). Las alertas en pantalla se actualizan mientras esta página está abierta; no hay vigilancia persistente al cerrar el navegador.

TiempoMDZ prioriza avisos oficiales. Las publicaciones de redes sociales sirven como contexto, pero no disparan alertas automáticas si no se pueden verificar.
